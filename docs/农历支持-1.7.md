# 重要日子：农历支持

公历和农历是并列的日期类型。农历记录保存用户输入的年份（可选）、月份、日期、是否闰月和每年重复开关。对应公历只用于展示、排序、倒计时和提醒，不替代原始日期。

## 明确的日期规则

- 支持**农历年份1900—2100**，包括这些农历年的腊月在下一公历年发生的日期。转换范围对应公历1900年1月31日至2101年1月28日。
- 每年重复时，逐年寻找相同农历月日，普通月与闰月严格区分。例如普通六月生日不在闰六月再重复一次。
- **某年没有所选闰月或三十，就跳过该年。** 不退到普通月份，不改为二十九，不改写原记录。记录了农历腊月三十时，下一次可能相隔多年；表单和详情解释规则，列表显示完整的下次公历年月日。
- 填写原始年份时，该年必须存在所选月份和日期；不重复日期必须填写年份。未来原始年份以前不产生重复提醒。
- 支持范围内没有下一次日期时，保留记录及编辑入口，显示“暂无下次日期”，不生成倒计时或提醒。一次性日期过去后仍显示在“过去的日子”。
- 提醒继续采用单个提前节点和当天节点；首页默认14天，自定义提前天数更大时沿用该窗口。关闭软件即退出，全部换算离线完成。

## 依赖与许可

采用[6tail/lunar-typescript](https://github.com/6tail/lunar-typescript)，锁定**1.8.6**，无第三方运行依赖，提供ESM、CommonJS和TypeScript类型，可同时用于Electron主进程与Vite界面。

项目采用[MIT许可](https://github.com/6tail/lunar-typescript/blob/master/LICENSE)。完整版权及许可文本存放在`app/assets/third-party/lunar-typescript-LICENSE.txt`，随软件资源和源码包一同交付。仅使用日期、月份及转换能力，不呈现库中的其他历法或民俗功能。

库负责农历月份、闰月、月长与公历转换；应用只负责支持范围、重复日期选择、自然日距离及提醒规则，不自行编写农历算法。

## 验证依据

`app/tests/lunar.test.ts`使用[香港天文台公历与农历对照表](https://www.hko.gov.hk/tc/gts/time/conversion.htm)的独立日期样本，覆盖1901年春节、2025年普通六月与闰六月、2026与2027年的五月初六、2033年闰十一月及2100年边界。

全范围检查逐个有效农历日期的公历连续性，并在每个月首日和末日进行双向换算。额外验证春节前的上一农历年、跨公历年14天提醒、缺三十连续跳年、闰月间隔多年、去重、一次性日期、范围耗尽、旧版数据库和备份迁移、损坏农历备份拒绝覆盖。

这些验证区分了库的双向一致性与外部独立对照，不将自我往返等同于对所有日期的权威认证。香港天文台对遥远未来接近午夜的新月和节气也说明了可能的一日预测差异，后续升级历法库仍需重跑对照与边界测试。
