# Windows 安装、升级与旧版迁移

## 安装身份和资料位置

正式版继续使用Electron及electron-builder的NSIS，不更换安装框架。固定App ID为`local.suishouji.desktop`，固定NSIS GUID为`42be8a92-8942-4f4c-9e2c-90bd703acc4c`；后续版本不得重新生成。软件名称和正式版快捷方式名称均为“随手记”。

程序默认位于当前用户Programs目录；首次安装可选择存放位置，选择`E:\soft`这类软件总目录时使用独立的`E:\soft\随手记`，不要求用户手动创建。已经选到“随手记”或“suishouji”目录、或已验证的本软件位置时不再套一层。目录页执行无副作用预览，下一页显示最终程序位置；开始安装时再次验证，正式升级沿用注册的位置并跳过重复的位置选择。资料始终保存在`%LOCALAPPDATA%\随手记`，不带版本后缀。数据库仍为版本3，正文、公农历日子、附件相对路径和提醒状态格式不变。布局及上次记录继续保存在资料目录的Local Storage，窗口设置在`.运行缓存/window-state.json`。

Portable继续使用程序旁的“我的数据”，实例锁、窗口标题和桌面入口与正式版区分。两种版本后续修改各自独立，不隐式同步。

## 三种安装路径

1. **全新安装**：没有可靠识别到旧程序，按正常方式安装，首次打开可开始记录。无法识别的旧路径仍可通过现有导入入口明确选择。
2. **正式版升级**：从固定注册项识别已有位置，正常保存退出后直接更新程序。已有资料、初始化标记或迁移状态存在时，不再发现和复制Portable资料，不要求换目录或重新导入。
3. **旧Portable迁移**：联合读取exe产品名称、版本及ASAR中的包名、主入口和发行类型，配合SQLite文件特征识别。候选仅限所选旧目录、安装包所在目录和本产品桌面入口，不扫描磁盘。旧Portable目录完整保留，正式程序安装在标准位置或已有正式位置，安装器会说明最终位置。

没有新目录标记或没有注册信息的旧正式程序，只要exe和ASAR身份可靠，也可识别为本软件。单独伪造目录标记不能绕过未知目录保护。总目录中的其他软件不归本安装器所有，不写入也不卸载；如果最终的“随手记”子目录包含未知文件，仍会拒绝安装，而不会继续套子目录来绕过检查。资料目录及其父子目录、最终的磁盘根目录和链接目录仍会被拒绝；检查发生在移除旧程序之前。

## 一次性迁移与失败恢复

安装器先正常关闭旧程序，等待保存完成；没有强制结束笔记进程的路径。保存、备份或关闭失败会以非零状态停止安装。

识别到Portable且正式资料尚未初始化时，安装器会先复制原数据，逐文件以系统.NET SHA-256核对并生成清单。原件不移动、不删除。准备的副本与请求记录位于资料目录旁的`.随手记-迁移/prepared/操作编号`，不是活动资料路径。

程序安装完成后，新版本自身的无界面维护入口会继续验证清单、数据库、正文和附件，在暂存副本中迁移，创建可恢复ZIP，再按日志发布到稳定资料目录。发布后对手记、附件、重要日子及提醒状态进行内容核对，通过后才提交；失败则回退并保留请求，可重跑安装包继续。安装中断后首次启动也能继续处理已准备的请求。

`安装迁移状态.json`、原有初始化标记和已有有效数据共同决定是否完成初始化。成功迁移会保存来源与备份位置，清除待处理请求。中断发生在提交之后时，使用已有迁移记录识别完成结果，不重复导入。后续版本走正式升级，不再复制原Portable。

如果正式资料已存在，即使同时发现Portable或遗留迁移请求，也优先保留正式资料，绝不覆盖或合并。备份损坏会阻止迁移，不会以空数据库冒充成功。详细失败原因保存在本机迁移工作目录，原始数据和备份不删除。

## 卸载、备份与日常升级

卸载默认只移除程序，`deleteAppDataOnUninstall=false`，资料、设置、每日备份和迁移备份都保留。重新安装读取同一资料目录。每日七份备份、手动完整ZIP和HTML导出继续提供；程序升级和数据备份是独立能力。

安装版还会在程序版本变化后、Store有机会升级数据库结构之前，创建并验证旧数据ZIP。当前没有改变数据库格式。

## 构建和实际验收

- `npm run package:all`：构建正式安装包和Portable。
- `npm run release`：本地归档安装包、Portable、源码及SHA-256清单，不包含个人资料。
- `npm test`：数据、编号、农历、迁移日志、初始化保护、自动迁移完整性及提交前校验回退。
- `node scripts/package-installer.mjs --location-qa`：生成独立App ID、GUID和快捷方式的当前版验收包。QA包必须传入`MEMO_INSTALL_QA_LOCALAPPDATA`，否则拒绝安装。
- `npm run test:installer-upgrades`：真实1.8.1到1.8.2升级，以及Portable自动迁移、无标记旧目录、伪造标记和未知文件保护、重复迁移防护、卸载重装、安装中断修复、安装包位于旧目录、旧数据库损坏等场景。兼容的`test:installer`和`test:installer-location`也指向这套隔离验收。
- `npm run test:installer-folders`：仅检查本次目录改动，包括自动子目录、预览无副作用、同名占用保护、真实安装和覆盖不重复嵌套、卸载保留周围文件。不会运行编辑器、农历或整套迁移回归。

验收需要先从真实1.8.1源码构建其QA安装包；当前源码禁止使用“降低版本号”来伪造旧版基线。测试目录位于工作区`.artifacts/tests`，不卸载或覆盖正式安装。

当前构建尚未配置数字签名，也未在另一台实体电脑或独立Windows虚拟机验收。按用户要求不使用电脑使用技能，原生安装器的鼠标点击未做自动验收；安装及迁移链路由真实安装器、命令行和应用接口验证。
