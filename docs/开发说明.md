# 随手记

个人离线图文记录软件。Windows x64、免安装，程序旁的“我的数据”保存 SQLite 数据库及附件。

## 开发

先进入 `app/`。Node.js 24+。`npm ci --cache ../.cache/npm` 安装锁定依赖，`npm run setup` 下载开发用 Electron 并生成图标，`npm run dev` 启动。`npm test` 验证存储、备份、恢复及导出；`npm run test:ui` 验证实际 Electron 界面。测试资料统一写入根目录 `.artifacts/tests/`。

`npm run package` 构建并打包到根目录 `.artifacts/staging/win-unpacked`；`npm run release` 把程序和源码包写入 `release/packages/`，首次交付时自动整理到 `release/随手记`。已有安装时保留旧程序。正常关闭已安装程序后，运行 `node scripts/upgrade.mjs`：先完整备份到 `private/upgrade-backups/`，再交换程序目录并保留原数据，用 SHA-256 验证数据库和附件一致；失败会回滚。日常运行打包程序不需要 Node.js。

1.1.0 使用暖白、靛蓝、珊瑚及少量紫色的配色。体验检查：`node scripts/ux-test.mjs`，覆盖 Ctrl+N / Ctrl+F、空白记录复用、上次记录恢复和顶部附件入口。指定 `NOTES_PACKAGED_EXE` 环境变量可针对已打包 exe 运行窗口测试。

## 结构

- `electron/`：SQLite、本地附件、备份恢复、HTML 导出、IPC 和桌面窗口。
- `src/`：React + Tiptap 中文界面，500ms 自动保存和退出前保存。
- `tests/`：真实临时目录和真实 SQLite 的数据验证。

SQLite 使用 Electron 自带 Node.js 的 `node:sqlite`，不依赖单独安装的数据库或原生扩展。富文本存 JSON，图片以资源编号关联，文件路径为相对路径。界面无 Node 权限，只经预加载脚本调用白名单 IPC。运行时禁止外部网络资源。

自动备份为每日启动时的快照。备份采用 SQLite 一致快照及 SHA-256 校验，ZIP 流式写入。恢复先解压校验到临时目录，保留恢复前备份，再通过磁盘日志替换数据。若恢复中断，下次启动会回滚未完成的替换。

旧 Word 文档可作为附件或手动复制，不包含批量转换、同步或 OCR。
