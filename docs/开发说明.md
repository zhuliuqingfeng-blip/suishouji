# 随手记

个人离线图文记录软件。Windows x64、免安装，程序旁的“我的数据”保存 SQLite 数据库及附件。

## 开发

先进入 `app/`。Node.js 24+。`npm ci --cache ../.cache/npm` 安装锁定依赖，`npm run setup` 下载开发用 Electron 并生成图标，`npm run dev` 启动。`npm test` 验证存储、备份、恢复及导出；`npm run test:ui` 验证实际 Electron 界面。测试资料统一写入根目录 `.artifacts/tests/`。

`npm run package` 构建并打包到根目录 `.artifacts/staging/win-unpacked`；`npm run release` 把程序和源码包写入 `release/packages/`，首次交付时自动整理到 `release/随手记`。已有安装时保留旧程序。正常关闭已安装程序后，运行 `node scripts/upgrade.mjs`：先完整备份到 `private/upgrade-backups/`，再交换程序目录并保留原数据，用 SHA-256 验证数据库和附件一致；失败会回滚。日常运行打包程序不需要 Node.js。

1.1.0 使用暖白、靛蓝、珊瑚及少量紫色的配色。体验检查：`node scripts/ux-test.mjs`，覆盖 Ctrl+N / Ctrl+F、空白记录复用、上次记录恢复和顶部附件入口。指定 `NOTES_PACKAGED_EXE` 环境变量可针对已打包 exe 运行窗口测试。

## 结构

- `electron/`：SQLite、本地附件、备份恢复、HTML 导出、IPC 和桌面窗口。
- `src/`：React + Tiptap 中文界面，500ms 自动保存和退出前保存。
- `tests/`：真实临时目录和真实 SQLite 的数据验证。

SQLite 使用 Electron 自带 Node.js 的 `node:sqlite`，不依赖单独安装的数据库或原生扩展。富文本存 JSON，图片以资源编号关联，文件路径为相对路径。界面无 Node 权限，只经预加载脚本调用白名单 IPC。运行时禁止外部网络资源。

自动备份为每日启动时的快照。备份采用 SQLite 一致快照及 SHA-256 校验，ZIP 流式写入。恢复先解压校验到临时目录，保留恢复前备份，再通过磁盘日志替换数据。若恢复中断，下次启动会回滚未完成的替换。

旧 Word 文档可作为附件或手动复制，不包含批量转换、同步或 OCR。

## 1.2 批量操作与布局

`npm run test:workspace` 覆盖实际窗口中的多选、事务失败、撤销、拖动、收起、窗口记忆和永久删除失败重试。排序通过 `Filter.sort` 传到本地存储层；批量 IPC 返回成功、失败、取消和撤销信息，原有单条接口仍可用。

批量移入回收站及恢复使用事务；撤销令牌仅在10秒内有效，并核对原删除时间，避免恢复后续已变化的记录。永久删除逐项暂存附件，数据库提交后清理；中断启动时会恢复未提交附件或清理已提交暂存，失败项可重试。

界面布局、排序保存在当前程序的本地存储；窗口普通边界和最大化状态保存在“我的数据/.运行缓存/window-state.json”。不修改原笔记表结构。分隔线支持拖动、双击重置和键盘方向键调整。

项目根目录是本地 Git 仓库，个人记录及升级备份位于已忽略的目录中。提交前使用 `git ls-files` 核查，打包源码采用明确的源码和文档清单，不递归打包工作目录。

## 1.2.1 纯文本操作

`src/plain-text.ts` 从编辑器模型提取选区或全文，保留文本块、空行、软换行，排除图片和隐藏链接地址。粘贴直接构造无标记的文本节点，不解析 HTML，保留目标段落布局；前后设置历史分组边界，支持单独撤销。切换记录后重新初始化编辑器状态，隔离撤销历史。

主进程提供类型化的纯文本剪贴板读写及原生菜单 IPC。Electron 44 的剪贴板接口是异步的，写入完成后才提示成功；读取后核对记录、文档及选区，防止粘贴串写。仅用户主动调用时读取剪贴板。原生正文菜单保留剪切、复制、粘贴、全选，并增加纯文本操作；工具栏使用单个“纯文本”入口。

`npm run test:clipboard` 使用隔离笔记及真实系统剪贴板验证快捷键、菜单路由、选区保留、全文、空剪贴板、读写失败、异步换记录、回收站只读和920px窄窗口布局。测试会先缓存并在退出时还原剪贴板。设置 `NOTES_PACKAGED_EXE` 可验证成品。

## 1.3.0 界面重设计

`src/style.css` 统一导航、列表、编辑区、菜单、提示和对话框的颜色、字号、边框及状态。界面资源、字体仍完全本地；桌面图标同步为墨蓝与陶土色。保留原有布局配置、默认栏宽和笔记数据结构。

顶部布局与记录操作合并为一行，保存状态移到固定页脚。编辑器工具栏使用 sticky 定位，编辑器的滚动边距确保长文输入光标在工具栏下方可见。按编辑区、导航和列表自身宽度使用容器查询，收起侧栏、拖动分栏或窄窗口时均适配。面板显式设置层叠顺序，保证设置菜单不被相邻栏遮住。

`npm run test:design` 使用虚构资料生成截图，并检查实际按钮边界与点击命中、跨栏菜单、长文编辑光标、文字对比度、多选和空状态。验收截图在 `.artifacts/tests/design-1.3/`，审核后可复制示例到 `docs/images/`。测试窗口按顺序运行，避免桌面焦点相互干扰。

## 1.4.0 场景与表现层重建

主界面以顶部空间导航、整页手记库和独立书写页组织。`layout.tsx`管理`view`、`indexWidth`、`indexHidden`、`filtersCollapsed`和`focused`，通过`suishouji:workspace:v2`持久化。目录只在书写时按需显示，手记库使用全部空间；旧三栏布局配置不再参与渲染，但保留其本地配置以便回退。

`openNote`在成功保存和读取记录后切换书写场景，`openLibrary`在保存成功后返回索引。新建和搜索使用独立的待聚焦请求，搜索清除旧的编辑器聚焦请求，避免连续复用空白记录后抢走搜索焦点。批量操作失败时展开目录以保留重试入口，事务和数据库结构沿用。

格式工具位于滚动纸张之外，元信息在宽书写区作为侧注，窄区移动到纸张下方。菜单、选择提示、空状态、只读页及全局保存状态均使用新的视觉系统。截图和设计理由见`视觉重置-1.4.md`。

`assets/icon.svg`是品牌图标唯一源。`scripts/icon.mjs`通过隔离的隐藏Electron窗口渲染PNG及16、20、24、32、40、48、64、128、256px原生ICO；辅助进程仅使用`.cache/icon-render/`。界面直接引用SVG，桌面及任务栏采用多尺寸ICO。

界面测试按新访问路径操作：从手记库点击记录进入书写，Ctrl+F展开目录，顶部切换回收站后选择记录查看。`test:design`生成`.artifacts/tests/design-1.4/`的整页索引、书写页、目录、批量筛选、窄窗口、专注和异常状态截图；原剪贴板、图文备份、批量与便携验收继续执行。

## 1.4.1 手记库顶部空间

`libraryHeaderHeight`追加到现有界面偏好，旧配置缺失字段时采用166px。`LibraryHeightSplitter`观察标题区和列表实际尺寸，配合CSS弹性收缩保证小窗口至少保留160px列表空间；标题区范围56–240px。分隔条位于表头与首条记录之间，支持上下拖动、方向键、Home/End和双击复位。键盘和拖动起点读取当前实际尺寸，避免快速操作使用滞后的观察值。

搜索、筛选、排序、多选和表头独立于可压缩标题区域。标题区低于110px时简化说明内容；“紧凑视图”设置56px并将记录行约79px收为约62px，保留标题和摘要。高度持久化，书写页的目录宽度与正文布局独立。

`test:library`使用18条虚构记录检查拖动上下限、键盘、双击、紧凑/舒展、可见数量、搜索与多选、重启记忆和窄窗口。所有截图仅含虚构资料。

## 1.5.0 默认首页

`Home.tsx`、`home.css`独立组织首页，`home-model.ts`计算最近三条更新、最近七个本地日期内更新的记录数及有效的上次记录。首页使用完整的有效记录摘要，不受手记库搜索、标签、排序和回收站范围影响；最近排序不继承置顶优先。没有上次记录时明确标为“最近的一条”，不会把它写成上次记录。

布局的`view`扩展为`home | library | document`；每次初始化固定`home`并解除专注，但继续读取旧的栏宽、目录开关、筛选收起及顶部高度。界面偏好仍使用原本地存储键，数据库无迁移。记录仍由原编辑器及保存接口管理，启动只读取、不创建。主动打开/新建时更新`suishouji:last-note`；浏览列表和批量操作产生的临时正文预览不再覆盖它。

返回首页先等待保存，失败则保留书写页；首页Ctrl+F进入完整手记库后聚焦搜索，清除陈旧的编辑聚焦请求。从首页打开记录会重置列表范围，避免带入上一次搜索或回收站。自动备份取真实文件修改时间，手动备份完成时记录ISO时间，避免中文日期解析及日期字符串时区偏移。

`test:home`使用独立资料验证默认入口、旧偏好、最近状态、继续上次、空数据、备份取消/成功、回收站更新、保存失败、快捷键及窄窗口。原视觉、图文、剪贴板和工作区脚本按真实路径从首页进入对应场景。窗口测试串行运行；不以测试模式跳过首页。
