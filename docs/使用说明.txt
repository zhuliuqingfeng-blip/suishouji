随手记 · 本地个人图文记录
========================

一、开始使用
双击“随手记.exe”打开。无需安装 Node.js、Python 或数据库。
点击右上方“新建记录”，直接输入文字。标题可以不填，列表自动显示正文首行。
停顿约半秒自动保存；关闭窗口前会完成保存。底部状态栏显示“所有更改已保存”即可放心。
关闭窗口即退出软件，不在后台驻留。
软件会记住上次使用的手记库或书写场景；在手记库可点击“继续上次的记录”。
窗口内可按 Ctrl+N 新建、Ctrl+F 搜索、Ctrl+S 立即保存。
在搜索框中按 Esc 清除搜索；连续新建时会继续使用当前的空白记录。

二、图片与文件
截图后按 Ctrl+V 粘贴图片；也可以把图片或文件从资源管理器拖进记录。
点击工具栏图片按钮或“添加附件”，可以选择文件。
也可直接点击窗口右上方“图片 / 文件”，长记录无需滚动到底部。
图片选中后可以选小、中、大三种显示宽度；点击图片查看原图，Esc 关闭。
附件保存独立副本，原文件移动或删除后仍能打开。点击附件使用系统默认软件打开。
文件夹请先压缩成 ZIP 再添加。Word 文件可作为附件保存。
粘贴网页文字时不会自动下载远程图片；请单独复制图片或保存图片后添加。

2.1 纯文本复制与粘贴
选中正文文字，按 Ctrl+Shift+C，或右键选择“复制为纯文本”。
粘贴时按 Ctrl+Shift+V，或右键选择“粘贴为纯文本”。
工具栏“纯文本”按钮也提供以上操作，点击按钮不会丢失已选中的正文。
纯文本保留换行及空行，去掉来源的字体、颜色、加粗和链接格式；图片及附件不混入文字。
粘贴位置已有的段落、标题或列表布局会保留；粘贴文字不继承周围的加粗和链接。
右上角“更多记录操作 → 复制全文为纯文本”，可复制当前标题和全部正文，包括刚输入的文字。
没有选择文字时不会误复制全文；剪贴板只有图片时，纯文本粘贴不会导入图片。
普通 Ctrl+C、Ctrl+V 继续保留格式；截图仍用 Ctrl+V 粘贴。
纯文本粘贴可以撤销、重做，且与前后输入分开撤销。切换记录后撤销只影响当前记录。

三、手记库与书写页
手记库按行展示记录，标题、标签、附件数量和时间对齐，便于查找。
点击一条记录进入书写页；左上角“手记库”可返回整页索引。
顶部“手记库”“回收站”切换记录空间；右上角滑杆图标打开“数据与设置”。
记录的创建时间、修改时间等位于纸张旁边；窄窗口时排到纸张下面。
搜索可匹配标题、正文、标签和附件名称，不搜索附件内部或图片中的文字。
在“添加标签”处输入后按回车。标签可在手记库及记录目录的筛选区使用。
图钉用于置顶记录。“更多记录操作”里可移入回收站。
回收站中的记录可以恢复，永久删除和清空回收站前会再次确认。

3.1 多选与批量删除
点击记录列表上方“多选”，勾选记录后点击“删除所选”。
也可按住 Ctrl 点击多个记录，或使用 Shift 点击连续选择。
“全选当前结果”仅选择当前搜索、标签筛选后的记录；更换筛选会取消选择。
列表获得焦点时可按 Ctrl+A 全选、Delete 删除、Esc 取消选择。
在正文或标题里，Ctrl+A 和 Delete 仍然只编辑文字。
移入回收站后右下角提供10秒“撤销”。超时后仍可从回收站恢复。
回收站支持批量恢复及永久删除，永久删除失败的项目会保留供重试。
右键记录可直接置顶、导出、删除或进入多选。

3.2 目录、专注与排序
手记库中，“序、记录、标签”等表头下方的分隔线可上下拖动。
向上拖会压缩标题说明区域；双击恢复默认，选中分隔线后也可按上下方向键调整。
点击排序旁的“紧凑视图”，可一次缩小顶部及行距，显示更多记录；“舒展视图”恢复常规布局。
搜索、筛选、表头仍会保留；顶部高度会记住，窗口变小时自动为列表留出空间。
书写页上方的目录按钮可展开记录目录，点击目录中的一行可切换记录。
拖动目录右侧分隔线调整宽度；双击恢复350px默认宽度，也支持方向键调整。
目录可独立关闭；Ctrl+F会自动展开目录并聚焦搜索框。
专注按钮可隐藏顶部导航及目录，再次点击恢复原来的目录状态。
格式工具始终位于纸张外，不随长记录滚动；窄窗口会自动换行。
书写区较窄时，图片/文件入口只显示加号图标，悬停可查看提示。
“筛选”可收起或展开标签；排序可选最近修改、最近创建或标题，置顶始终优先。
软件会记住窗口大小和位置、浏览/书写场景、目录宽度及开关、筛选收起状态和排序方式。

四、备份与恢复
每天第一次打开软件时自动备份，保留最近七份，位于“我的数据/自动备份”。
“数据与设置 → 备份全部数据”可将全部记录、图片、附件和回收站打包成 ZIP。
建议偶尔将备份另存到 U 盘或另一块硬盘。
“从备份恢复”会先校验备份，再把当前数据备份到“我的数据/恢复前备份”，然后恢复。
校验失败不会覆盖当前数据。
“导出全部记录”生成 HTML 和配套附件；打开“打开我的记录.html”即可用浏览器阅读。

五、换电脑或移动位置
先关闭软件，然后复制整个“随手记”软件文件夹到另一台 Windows 64 位电脑。
请务必包含“我的数据”文件夹。不要只复制 exe；其余资源也是程序的一部分。
在新位置双击“随手记.exe”即可继续使用，无需联网。
不要把软件放在无写入权限的系统目录或只读介质中。

六、桌面快捷方式
右键“随手记.exe” → 显示更多选项 → 发送到 → 桌面快捷方式。
也可在程序文件夹中查找配套的桌面快捷方式创建脚本（如有）。

七、隐私与故障
程序不注册账号，不上传记录，不自动联网，不加载远程字体或远程图片。
点击记录中的网页链接会使用默认浏览器访问该网页。
数据位置可在“数据与设置 → 使用说明与数据位置”中查看。
保存失败会保留当前文字并提示重试；有未保存内容时不会直接退出。
请保留完整“我的数据”文件夹，以便恢复。
