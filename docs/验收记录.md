# 随手记 1.1.0 验收记录

验收日期：2026-10-16。环境：当前 Windows x64 电脑。交付程序使用 Electron 自带的运行环境，日常使用无需安装开发工具。

## 构建与数据测试

- TypeScript 检查、前端构建、Windows x64 打包成功，exe 图标及版本信息已写入。
- 7 项真实 SQLite / 文件系统测试通过：中文持久化及整理、附件独立副本及迁移、完整备份恢复与无效 ZIP、HTML 导出转义、恢复中断回滚、保存失败与备份内容篡改校验、批量附件失败时整批回滚。

## 成品界面测试

通过 Playwright 启动真实打包 exe，经界面操作和 IPC 验证：

- 中文标题与正文，停止输入后自动保存；标签与置顶；文字和附件名称搜索。
- 使用真实系统剪贴板粘贴 PNG 图片，图片显示、放大及调整宽度。
- 添加文件后删除原文件，复制的附件仍完整；点击附件正确交给系统打开接口。为避免遗留外部窗口，测试用接口替身读取所传路径的实际文件内容。
- 插入网页链接、回收站删除与恢复。
- ZIP 备份及恢复，恢复前自动保留当前数据；HTML 和配套附件导出。
- 输入后立即切换记录、输入后立即关闭窗口，重新打开后内容完整。
- 运行时外部网络请求被禁止；本地图片协议仍可加载。
- 数据文件夹换位置后，图片与文件仍可访问。

## 整套便携与自动备份测试

另行在默认数据位置启动成品，验证每日自动备份、仅保留最近七份备份。创建含图片的验收记录后退出，移动整个程序文件夹，再从新路径启动，记录和图片均正常。已清除验收数据，交付的数据文件夹为空。

这些检查均在本机完成；未在另一台实体电脑上运行。已通过整套程序和数据迁移到不同路径的验证。备份中断恢复采用模拟磁盘恢复日志验证，未进行真实断电试验。

## 交付

- `release/随手记/`：可直接运行的软件、使用说明及快捷方式脚本。
- `release/随手记-1.1.0-Windows-x64.zip`：便携软件包，不包含个人数据。
- `release/随手记-1.1.0-源码.zip`：源码、锁定依赖、构建脚本、测试与说明；不包含 node_modules 或验收数据。

## 1.1.0 主题与使用体验检查

新主题使用靛蓝主色、暖白背景、珊瑚强调色，以及淡紫、浅杏色标签；程序图标和 HTML 导出配色同步更新。正文增至16px，列表和辅助文字提高字号与对比度。

开发模式及打包 exe 均通过原有界面回归和新体验验证：窗口内 Ctrl+N 新建、Ctrl+F 搜索、Esc 清除搜索、空白记录复用、顶部图片文件入口、记住上次查看的未置顶记录、Esc 关闭链接对话框。原有7项数据测试再次通过。截图已通过人工查看。

升级先正常关闭旧程序，再完整备份数据库及附件；替换程序时保留“我的数据”，用 SHA-256 比对升级前后的数据库和附件。升级校验结果另保存在 `upgrade-backups/` 对应目录。
