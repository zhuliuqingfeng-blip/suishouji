## 1.2.0 目录及工作区优化

日期：2026-10-19。环境：本机 Windows x64。所有自动验收均使用 `.artifacts/tests/` 或打包暂存目录的隔离资料，不编辑已安装软件中的个人记录。

### 目录与版本管理

先将源码和开发配置归入 `app/`，说明和示例归入 `docs/`，软件包归入 `release/packages/`，缓存、验收产物、个人升级备份分别归入 `.cache/`、`.artifacts/`、`private/`。保留已安装软件 `release/随手记/` 及桌面入口路径。

整理后验证 1.1 的构建、7项数据测试和窗口启动/体验检查，再初始化本地 Git 并提交基线 `e5e11e8`。Git 跟踪范围不含个人数据库、附件、备份、依赖和软件成品。1.2 功能单独提交。

### 自动测试与构建

- TypeScript 检查、生产构建、Windows x64 打包通过。
- 15项自动测试通过，包括原有存储/备份/导出测试、批量事务回滚、撤销期限与范围、永久删除失败重试及附件恢复、删除中断恢复、排序、窄窗口布局、连续选择和多显示器边界计算。
- 本地开发服务器和桌面窗口启动检查通过。

### 真实成品窗口检查

- Ctrl点击、Shift点击及Shift复选框连续选择，选择期间保持当前正文。
- 当前筛选结果全选、更换筛选取消选择；筛选更新期间禁止操作旧列表，防止误删隐藏记录。
- 批量删除统一确认一次，取消时不改数据；10秒撤销只恢复对应删除。
- 刚输入就批量删除，先保存草稿；删除当前记录后切到邻近记录；删除筛选结果不会切走未选中的正文。
- 通过数据库触发器模拟真实保存错误，确认保留编辑内容并阻止删除；解除错误后可以保存。
- 回收站批量恢复；模拟永久删除部分失败，界面保留失败选择并允许重试。
- 右键菜单可操作单条或所选记录，置顶不强制切换正文；排序选择重启后保留。
- 两栏分别拖动、双击复位、键盘调整；导航图标折叠、列表隐藏及专注模式恢复。
- 列表隐藏时Ctrl+F自动展开搜索；标题和正文中的Ctrl+A/Delete仍处理文字。
- 窄窗口保留至少400px正文区域；窗口大小、分栏宽度、收起状态重启后恢复，修复Windows缩放引起的尺寸漂移。
- 原有图文编辑、真实剪贴板图片、图片缩放、附件独立副本与打开路径、搜索、链接、回收站、ZIP备份恢复、HTML导出、立即切换和退出前保存均通过回归。
- 新旧体验测试均对真正打包的1.2.0 exe运行。

交付软件及源码压缩包位于 `release/packages/`；源码包只含明确列举的源码、配置、测试与文档，不包含个人数据。升级脚本在替换前完整备份并比对数据库、附件SHA-256；每次实际升级的校验日志保存在 `private/upgrade-backups/` 对应目录。
