# 随手记

个人离线图文记录软件，支持文字、图片、附件、搜索、标签和本地备份。

## 下载和使用

**[下载最新 Windows 免安装版](https://github.com/zhuliuqingfeng-blip/suishouji/releases/latest)**。仓库为私有，请先登录有访问权限的 GitHub 账号。

1. 在发行页面的 **Assets** 中下载 `suishouji-版本号-windows-x64.zip`。
2. 将整个 ZIP 解压到一个可写入的文件夹，双击其中的 `随手记/随手记.exe`。无需安装 Node.js 或数据库。
3. 软件包不包含个人资料。若要迁移原有手记和重要日子，请在旧电脑中选择“数据与设置 → 备份全部数据”，把备份带到新电脑后选择“从备份恢复”。

GitHub 的 **Code → Download ZIP** 以及发行页面中的 **Source code** 下载的是源码；运行软件请选择上面的 Windows 软件包。

个人记录保存在解压后的软件文件夹内的“我的数据”中；也可以在正常关闭软件后复制整个软件文件夹到另一台 Windows 64 位电脑。GitHub 不会自动同步个人记录。

## 开发

进入 `app` 目录执行 `npm ci --cache ../.cache/npm`、`npm run setup`、`npm run dev`。已有依赖时无需重复安装。

`npm run build` 构建，`npm test` 运行数据测试，`npm run test:ui`、`npm run test:ux` 和 `npm run test:workspace` 验证实际窗口。`npm run test:clipboard` 检查真实剪贴板、纯文本操作与窄窗口工具栏；`npm run test:dev` 检查开发服务器；`npm run test:portable` 检查打包暂存副本的整套搬迁。所有验收使用隔离数据。

`npm run package` 打包至 `.artifacts/staging/`，`npm run release` 生成便携包和源码包。正常关闭已安装程序后，执行 `node scripts/upgrade.mjs` 安全升级。
